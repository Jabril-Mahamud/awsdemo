# awsdemo

Generated by [Kreator](https://github.com/JabrilMahamique/Kreator).

## Stack


- Frontend: react

- Backend: fastapi
- Database: postgres
- Provider: aws (eu-west-1)

## Quick start

```bash
# Local development (Kind cluster with ArgoCD + Crossplane)
make dev

# Deploy to aws
make deploy

# Tear down
make destroy
```

## Local URLs

After `make dev`:


- frontend: http://frontend.localhost:9080

- Backend: http://api.localhost:9080
- ArgoCD: http://argocd.localhost:9080 (log in with `awsdemo / admin123` to see just this project, or `admin / admin123` for everything)


## Project structure

```
awsdemo/
  kreator.yaml          # Project config
  apps/

    frontend/        # react app (web)

    backend/            # fastapi app
  infrastructure/       # Crossplane XRDs, compositions, claims
  deploy/
    argocd/             # ArgoCD app-of-apps
    helm/               # Helm charts for web frontends and backend
  secrets/              # Sealed Secrets
```
